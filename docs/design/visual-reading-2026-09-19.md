# 画像で流し読みできるトップ・LP

本文の途中に挿絵を置く構成から、画像と短い見出しを追うと要点が伝わる構成へ変更した。詳細な説明はHTMLに保持し、利用者が開ける詳細領域に整理する。料金・適用条件は常時表示する。

## 反映範囲

- トップ: 表示画像を8から27か所へ。実案件3件、相談テーマ7件、支援内容3件、開発工程5段階などを画像で説明。
- ゼロスタート・強み: 各1から6か所へ。発注判断の材料、入力・保存・業務ロジック、要件へのフィードバック、既存資産の活用を図解。
- サービス・業界別LP: 課題と対応の共通セクションは大きな説明画像を先に表示し、本文を詳細領域へ保持。独自構成のAI開発、RAG、AI導入、経営DXにも画像を追加。
- 進め方: 工程ごとに画像と判断事項を表示し、役割分担と事例の全文は開閉領域に保持。

## 実装

- `reading-visual.astro`: 説明図、拡大リンク、alt、caption。
- `visual-card-image.astro`: リンクカード内で使える、リンクを内包しない画像とcaption。
- `service-reading-visuals.ts`: サービスごとに課題と対応の画像を選択。
- `visual-explanations.json`: 再利用するaltとcaption。

## 画像制作

OpenRouterの `openai/gpt-image-2` で11点を生成。実費合計 $1.82258。配色・日本語・図の意味を目視で確認し、WebPと768px版を保存。プロンプトと実費は `lp-reading-visuals-2026-09-19.json` と `home-case-visuals-2026-09-19.json` に記録した。

実績の図は既存本文の事実をもとに制作し、期間は個別案件の実績であることをcaptionに明記。トップの既存データ文言は変更しておらず、開閉領域を含めたレンダリング後のHTMLに残ることを照合した。

コードと画像はローカル反映。本番デプロイは別途。
